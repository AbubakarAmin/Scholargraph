## Module Overview

Demo script for the multi-agent research system.
Runs with mock data for testing purposes.

# `demo.py`
![Docs version](https://img.shields.io/badge/docs‑v2024.09‑blue)

## Responsibility

Offline demonstration using mock agent implementations. It is useful for showing the orchestration shape without live scholarly or LLM services.

## Limitation

The demo mocks agent behavior and should not be used to evaluate research quality, source availability, sandbox safety, or generated evidence.
